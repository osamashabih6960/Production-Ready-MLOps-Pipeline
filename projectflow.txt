    data/raw/ai4i2020.csv
              ↓
      data_ingestion.py
              ↓
         Read CSV
              ↓
      Validate Columns
              ↓
    data/processed/ai4i2020.csv

Purpose:
    1. Read raw dataset
    2. Validate required columns
    3. Create processed directory
    4. Save processed copy


============================================================

5. DATA PREPROCESSING
---------------------

File:
    src/data_preprocessing.py

Run:
    python src/data_preprocessing.py

Flow:

    data/processed/ai4i2020.csv
              ↓
         Load Dataset
              ↓
    Remove unnecessary columns
              ↓
    Remove leakage columns
              ↓
       Handle missing values
              ↓
      Convert Type → numerical
              ↓
       Separate X and y
              ↓
        Train/Test Split
              ↓
        Feature Scaling
              ↓
     Save processed datasets

Removed columns:

    UDI
    Product ID
    TWF
    HDF
    PWF
    OSF
    RNF

Reason:

    UDI / Product ID
        → Identifier columns

    TWF / HDF / PWF / OSF / RNF
        → Failure-mode indicators
        → Avoid target leakage

Type conversion:

    L → 0
    M → 1
    H → 2

Train/Test Split:

    Training → 80%
    Testing  → 20%

    random_state = 42
    stratify = y

Scaling:

    StandardScaler

Output:

    data/processed/X_train.csv
    data/processed/X_test.csv
    data/processed/y_train.csv
    data/processed/y_test.csv

11. DVC — DATA VERSION CONTROL
------------------------------

Purpose:

    Track dataset versions separately from Git.

Dataset:

    data/raw/ai4i2020.csv

If CSV is already tracked by Git:

    git rm --cached data/raw/ai4i2020.csv

Then:

    dvc add data/raw/ai4i2020.csv

DVC creates:

    data/raw/ai4i2020.csv.dvc

Concept:

    Git
      ↓
    Code + Configuration

    DVC
      ↓
    Dataset Versioning
