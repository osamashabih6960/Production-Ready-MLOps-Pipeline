5. DATA PREPROCESSING
---------------------

File:

    src/data_preprocessing.py

Run:

    python src/data_preprocessing.py

Flow:

    Processed Dataset
          ↓
    Remove unnecessary columns
          ↓
    Remove leakage columns
          ↓
    Handle missing values
          ↓
    Convert categorical values
          ↓
    Separate X and y
          ↓
    Train/Test Split
          ↓
    StandardScaler
          ↓
    Save datasets

Removed:

    UDI
    Product ID
    TWF
    HDF
    PWF
    OSF
    RNF

Type Conversion:

    L → 0
    M → 1
    H → 2

Split:

    Train → 80%
    Test  → 20%

    random_state = 42
    stratify = y

Output:

    X_train.csv
    X_test.csv
    y_train.csv
    y_test.csv
